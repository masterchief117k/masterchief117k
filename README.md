### 🚀 Featured projects

#### 🛡️ [I.V.S.S. — Intelligent Video Surveillance System](https://github.com/masterchief117k/Final-year-project-)
<sub>Final-year project · real-time computer vision</sub>

A live surveillance dashboard that recognises employees, flags strangers, detects knives and notices when someone covers the camera — all from a webcam feed.

- **Three-model pipeline:** SSD-ResNet face detection → OpenFace embeddings for recognition → YOLOv5s weapon detection, plus a brightness heuristic for tampering
- **Multithreaded inference** keeps the stream at **~30 FPS vs ~10 FPS** single-threaded, cutting main-loop blocking from 96 ms to ~1 ms per frame
- **Real-time alerts** pushed over Flask + Socket.IO, bcrypt-secured admin login, SQLite logs for attendance and incidents
- **Deployable:** Dockerfile + nginx config, with a reproducible latency benchmark script
